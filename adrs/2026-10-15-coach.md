# 2026-10-15 - Coach rules, `insights` and the 💡 part

## Status

Accepted

## Context

The index (2026-10-15-transcript-index.md) says where money went. Users still
had to work out what to change. antiburn ships checks with a $ estimate and a
fix; its thresholds are in the 2026-10-10 analysis (A§4.4, A§4.7, A§4.10).

## Decision

- Pure rules (`src/rules.ts`, Node-free so the mod can bundle them) over the
  rollups and the usage history; each finding has an id, an estimated
  avoidable $ (or none), evidence and a fix (`setting` | `env` | `command` |
  `habit`). Setting and env names are checked against the vendored Claude
  Code docs.
- The refresher writes the week's findings to `feed.json.advice`; `insights`
  prints them; the statusline shows the top one as part 14, on its own row by
  default.
- Snooze per rule in `config.json`. The CLI never edits Claude Code settings.
- R7 waits for CLI-10. R10 uses carry share only.

## Options considered

| Option                      | Why not / why                                                     |
| --------------------------- | ----------------------------------------------------------------- |
| Run the rules in the render | The index is not read on the render; one feed read is cheaper     |
| Auto-apply fixes            | Out of scope (handoff non-goal: no auto-fix without confirmation) |
| LLM-based checks            | Out of scope; deterministic rules are testable to the cent        |

## Consequences

- The default layout gains a second row when a finding exists.
- A $0.50 floor hides small findings; the floor is a fixed guess.
